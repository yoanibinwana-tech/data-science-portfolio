Project 01

Portfolio project one: identifying what separates top-tier D1 basketball

Research question

What statistical distributions — offensive rating, usage rate, and points per game — determine if a player is a Division 1 basketball player, and how do those distributions differ in top-tier programs compared to lower-tier ones?

Source collegebasketballdata.com — a clean, structured CBB data API with prebuilt packs
Unit of analysis Each row represents one player-season
Features Points per game (PPG), offensive rating and usage rate, field goal percentage (FG%), three-point percentage (3PT%), player position
Size D1 season data covering roughly 350+ teams and 4,000–5,000 rostered players
Missing values Vertical leap, wingspan

Conceptualized / operationalized variables

  • Offensive rating — conceptualized

    A player's overall scoring efficiency, estimating their true skill at generating points (Oliver, 2004).

  • Offensive rating — operationalized

    Points produced per 100 individual possessions used, calculated from field goals, free throws, assists, and turnovers (Oliver, 2004).

  • Usage rate — conceptualized

    How often a possession "runs through" a player, via a shot, free throw trip, or turnover (Oliver, 2004).

  • Usage rate — operationalized

    The percentage of a team's total possessions used by a given player while on the floor (Oliver, 2004).

  • Points per game — conceptualized

    Raw scoring output.

  • Points per game — operationalized

    Total points scored across the season divided by games played.

Project 02

Portfolio project two: does a rolling 7-day average improve weekly rainfall prediction?

Research question

How does incorporating rolling 7-day averages of rainfall improve the accuracy of predicting weekly precipitation compared to using raw daily data?

Source NCEI NOAA — National Centers for Environmental Information
Task Regression
Target variable Total precipitation over the seven days following the forecast day
Unit of analysis A forecast day paired with the total rainfall of the seven days that follow it
Features Raw daily rainfall for the previous 28 days, four 7-day rolling averages (7, 14, and 21 days before), and seasonality features
Size 5,418 daily forecast records
Missing values 0 missing days

Background

Predicting rainfall supports agricultural productivity and food security, and helps us anticipate drought. Machine learning has been used to predict rainfall from all kinds of atmospheric measurements. For example, Liyew and Melese (2021) compared multivariate linear regression, random forest, and XGBoost for daily rainfall amount, judging the models with MAE and RMSE. Another related study used lagged values of precipitation, temperature, and insolation to capture rainfall patterns.

Data cleaning

The data contained many columns about wind, snow, and other flags used in weather prediction, but my research question focused only on precipitation, so I kept the daily precipitation column and left out the rest.

Overall, the models show that incorporating rolling 7-day averages of rainfall does not improve the accuracy of predicting weekly precipitation compared to using raw daily data.
